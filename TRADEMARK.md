exists so that when someone sees the Sallyport name, they can be sure the
software actually comes from this project.

The code license ([LICENSE.md](LICENSE.md)) grants **no trademark rights**;
Apache-2.0 §6 is explicit about it. Your right to use, modify and
redistribute the code is never a right to the name.

## Allowed without permission

- Truthful, nominative statements: "compatible with Sallyport", "built on
  Sallyport", "a fork of Sallyport", "plugin for Sallyport".
- Linking to sallyport.dev or this repository; using the name in articles,
  reviews, talks and academic work.
- Redistributing **unmodified** official builds under their original name.

- Using the Marks, in whole or in part, in the name of your own product,
  service, company, domain, app, package or logo, including for forks and
  derived products, and including names confusingly similar to "Sallyport".
- Using the Marks in a way that implies sponsorship, endorsement or official
  status.

**Forks:** you are welcome to fork the code under its license, but a
distributed fork must be renamed and de-branded: replace the name, icon,
glyph and logo. A truthful "based on Sallyport" attribution is fine and
encouraged.
